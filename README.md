# 椿堂 JAPANESE NAME MAKER

**Your Name in Japanese Kanji** — 外国人のお客様の名前を、発音と意味の両方を考えた漢字の当て字（アートネーム）に変換する Web アプリです。

- HTML / CSS / JavaScript のみ（ビルド不要・APIキー不要で動作）
- スマートフォン・タブレット・PC 対応、PWA（ホーム画面に追加・オフライン動作）
- GitHub にそのままアップロードし、Vercel で公開できます

## 1. 画面の流れ

1. **言語**：15言語から選択
2. **名前**：名前と出身国・地域（発音の推定に使用）
3. **読み方**：カタカナの確認・修正、好みのイメージ、使いたい漢字
4. **漢字**：候補（原則5つ）、一文字ずつの意味、漢字の変更

候補の並び順：
- **椿堂のおすすめ**：名前の由来と漢字の意味がつながる当て字（例：John＝如恩。John の由来「神は恵み深い」と恩＝恵み）。説明文つき
- **日本人名と同じ漢字**：エマ・マリア・サラ・レオなど、日本人の名前にもある音は、実際の日本の名前で使われる漢字（恵麻・真里亜・紗良・玲央など）を最大2つ
- **テーマ別の候補**：美しさ・幸運・強さ・自然・伝統

## 2. フォルダ構成

```

js/config.js          設定（AI連携・候補数）

js/engine.js          漢字変換エンジン（候補生成・漢字の変更・AI候補の照合）
js/i18n.js            15言語の画面テキスト
js/countries.js       出身国・地域 → 発音ルール
js/ai.js              AI連携アダプター（初期版は無効）
js/app.js             画面の動き
data/kanji-db.js      漢字データベース（466字：読み・意味10言語・画数・カテゴリ・評価）＋除外漢字＋椿堂おすすめ＋日本人名と同じ漢字
data/names-db.js      外国人名の読み辞書（286名、国別の読み違いにも対応）

```

## 3. 公開手順（GitHub → Vercel）

1. GitHub で新しいリポジトリを作り、このフォルダの中身をすべてアップロード
2. [Vercel](https://vercel.com) で「Add New → Project」→ そのリポジトリを選択
3. Framework Preset は **Other**、Build Command・Output Directory は空欄のまま「Deploy」

ファイルを更新したら、`sw.js` の `CACHE = "tsubakido-v4"` の番号を上げると、お客様のスマホにも新しい版がすぐ届きます。

手元で試すときは `index.html` をダブルクリック、またはフォルダで `npx serve .`。テストは `node tests/test-names.js`。

## 4. 管理画面（漢字データの編集）

- `admin/index.html` をパソコンで開きます（ローカル用）
- 漢字の追加・削除・読みや意味の修正・一時除外／除外漢字／外国人名の読み／椿堂おすすめ当て字／編集中データでの変換テスト
- 「書き出し」で `kanji-db.js`・`names-db.js` を保存 → GitHub の `data/` のファイルと差し替えると公開アプリに反映
- 公開サイトでは `/admin` はトップへ転送されます。管理画面はブラウザ内でしかデータを変えないため、第三者が公開データを書き換えることはできません

### 定番の当て字のデータ

`data/kanji-db.js` の最後にあります。

- `recommended`（椿堂のおすすめ）：10名分（ジョン・ソフィア・ソフィー・ミア・ノア・イーサン・クレア・ステラ・ルシア・ルーシー）。管理画面の「おすすめ当て字」タブで追加・削除できます。説明文は日本語・英語の2つで、日本語以外の言語では英語を表示します
- `jpNames`（日本人名と同じ漢字）：52の読み。管理画面では編集できないので、このファイルを直接書き換えてください（管理画面から書き出しても消えません）

既存の当て字サイト・名付けサイトを調べ、よく使われる型を参考にしています。他サイトの組み合わせはそのまま写さず、読みと意味の事実をもとに椿堂として選び直しています。

## 5. 対応範囲

| 項目 | 対応済み | 制限 |
|---|---|---|
| 画面の言語 | 15言語 | 日本語・英語以外は初期翻訳。公開前にネイティブ確認を推奨 |
| 漢字の意味 | 日本語・英語・中国語（簡体/繁体）・韓国語・仏・独・西・伊・葡 | タイ語・ベトナム語・インドネシア語・アラビア語・ヒンディー語は英語で表示（画面にも明記） |
| 発音推定（標準） | 英・仏・独・西・伊・葡の綴り、中国語ピンイン、韓国語ハングル、ロシア語キリル文字、日本語ローマ字/かな＋名前辞書 | 辞書にない名前は推定。お客様が読みを確認・修正する流れ |
| 発音推定（簡易） | その他の国・地域 | 画面に「簡易版」と表示 |
| 入力文字 | ラテン文字、カタカナ/ひらがな、ハングル、キリル文字 | 漢字のみの名前・アラビア文字・タイ文字などは「ローマ字かカタカナで」と案内 |
| AI | 連携の仕組み・API・辞書照合を実装済み | 初期版は未接続 |

**テスト結果**：英語圏の名前100名＋各国18名＝118名すべてで候補を生成。112名で5候補以上、1名あたり約20ms。

## 6. AI連携を有効にする（将来）

1. Vercel の Settings → Environment Variables に `ANTHROPIC_API_KEY` を追加（コードには書かない）。必要なら `ANTHROPIC_MODEL` も
2. `js/config.js` の `AI_ENDPOINT` を `"/api/kanji-ai"` にして再デプロイ
3. AI の候補は漢字データベースと照合し、読みが成り立ち除外漢字を含まないものだけを「AI提案（辞書照合済み）」として表示。意味はデータベースのものを使用

## 7. 方針

- 結果は**創作的な当て字（アートネーム）**であり、正式な日本名ではないことを画面に明記
- 日本人の名前にもある響きは「この響きは日本人の名前にもあります」と表示
- 一般的な読みから外れる字には「創作的な当て字」「創作読み」を表示
- 否定的な意味の漢字（約100字）は候補にも「好きな漢字」にも使わない
