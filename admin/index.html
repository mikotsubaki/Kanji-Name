漢字データベース管理（ローカル用）

この管理画面はお使いのパソコンの中だけでデータを編集します。編集結果は「書き出し」でファイルにし、GitHub の data フォルダのファイルと差し替えて公開してください。 公開サイト（Vercel）では /admin へのアクセスは自動的にトップページへ転送され、誰もデータを書き換えられません。
漢字画数音訓名乗り意味評価

カテゴリー

名前に使わない漢字（否定的・不適切な意味）を並べて入力します。ここにある漢字は候補にも「好きな漢字」にも使われません。

よく使われる外国人名の読みを登録します。国によって読みが違う場合は「de:ミヒャエル, fr:ミカエル」のように書きます（en 英語 / fr / de / es / it / pt / nl / ru）。

綴り読み国別の読み

特定の読みに対して、椿堂おすすめの当て字を登録します。お客様の読みと一致すると候補の先頭に「椿堂のおすすめ」として表示されます。各漢字が漢字データにあり、読みが合う場合だけ表示されます。

読み漢字読みの割り当てメモ

編集中のデータで変換をテストできます。

公開用ファイルに書き出す

書き出した2つのファイルを、GitHub の data/ フォルダの同名ファイルと差し替えると、公開中のアプリに反映されます。

JSON で保存・読み込み

このパソコンのアプリで試す

編集データをこのブラウザのアプリだけに反映します（他の人には影響しません）。アプリ右上に「ローカル編集データ使用中」と表示されます。
