# 設計書 — 椿堂 JAPANESE NAME MAKER

## 目的
外国人のお客様が自分の名前を美しい意味の漢字（創作的な当て字＝アートネーム）に変換し、その意味を自分の言語で理解できるようにする。スマホで迷わず進められること。

## 画面構成と流れ
| アプリの画面 | 依頼書 | 内容 |
|---|---|---|
| 1 言語 | ① | 15言語を国旗と言語名で表示。選択はブラウザに記憶 |
| 2 名前 | ② | 名前入力＋出身国・地域（言語とは別に選択）。国名は表示言語で自動翻訳。推定の精度（標準/簡易）を表示 |
| 3 読み方 | ③④ | カタカナの確認・修正（カタカナ入力パッド付き、ローマ字併記）、複数語の名前は使う部分を選択、好みのイメージ（複数選択）、使いたい漢字 |
| 4 漢字 | ⑤⑥⑦ | 候補（原則5種類・テーマ別）、意味の詳細（開閉式）、1文字ずつ変更するシート |

ハンコ関連（⑧⑨：プレビュー・画像保存・注文）は今回の範囲から外しています。画面遷移は4段階にまとめ、各画面に「戻る」、ブラウザの戻るボタンにも対応。

## 変換の仕組み
1. **読み推定**（js/kana.js）：名前辞書 → 国別の綴り規則 → カタカナ。ハングル・キリル文字・ピンインは専用変換
2. **拍に分解**：マイケル → マ・イ・ケ・ル（ー・ッ・ンも1拍。外来音ジェ・フィ等は「ジ＋エ」のように2つの漢字にまたげる）
3. **漢字の当てはめ**（js/engine.js）：各漢字の音読み・訓読み・名乗り・創作読みを拍に照合。近い音（濁音↔清音、ヴ→ブ、ティ→チ等）は減点付きで許可
4. **評価**：発音のずれ、読みの自然さ（創作読みは減点）、意味のポジティブ度と名前適性、テーマ・好みとの一致、文字数（2〜4字を優先、5字以上は減点）、同じ字の重複、画数のバランス
5. **ビームサーチ**でテーマ（美しさ・幸運・強さ・自然・伝統）ごとに最良案を選び、似すぎた候補や品質の低い候補は除外（無理に5つ作らない）
6. 好きな漢字：音が合えば組み込み、合わなければ「意味優先」と明示して置き換え

## データ
- 漢字DB：漢字・画数・音読み・訓読み・名乗り・創作読み・カテゴリ・ポジティブ度・名前適性・意味（10言語）
- 除外漢字・椿堂おすすめ当て字・外国人名辞書（国別読み）
- 管理画面で編集 → JS/JSON 書き出し → data/ を差し替え

## 拡張ポイント
- AI：`api/kanji-ai.js`（APIキーはサーバー側環境変数）→ `engine.validateExternal()` で辞書照合
